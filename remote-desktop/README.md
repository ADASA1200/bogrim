# RDesk – שליטה מרחוק בסגנון AnyDesk

תוכנת שולחן עבודה מרוחק קוד-פתוח, כתובה ב-Python על בסיס **WebRTC**.
וידאו, עכבר, מקלדת, לוח, קבצים וצ'אט עוברים **ישירות בין המחשבים (P2P)**, מוצפנים (DTLS‑SRTP),
והשרת משמש רק לאיתות (הכרות בין שני הצדדים).

```
 צופה  ───── שרת איתות (WebSocket, הודעות SDP בלבד) ─────  מארח
   └────────── חיבור P2P מוצפן (STUN) / TURN כגיבוי ─────────┘
```

## התקנה

```bash
cd remote-desktop
pip install -r requirements.txt      # Python 3.10+, ‏tkinter מגיע עם Python ב-Windows
```

## הרצה

1. **שרת איתות** (על מחשב נגיש לשני הצדדים; בבדיקה מקומית – אותו מחשב):
   ```bash
   python -m rdesk server --host 0.0.0.0 --port 8765
   ```
2. **במחשב שרוצים לשלוט בו (מארח):**
   ```bash
   python -m rdesk host --server ws://SERVER_IP:8765
   ```
   יוצג מזהה וסיסמה. בלי ממשק גרפי: `--headless` (ועם `--unattended` לגישה בלי אישור).
3. **במחשב ממנו שולטים (צופה):**
   ```bash
   python -m rdesk viewer --server ws://SERVER_IP:8765
   ```
   מזינים מזהה וסיסמה, והמארח מאשר.

הגדרות נשמרות ב-`~/.rdesk/config.json`. אפשר לקבוע בו `"password"` קבוע.
אם אין STUN זמין (רשת פנימית), `RDESK_STUN=""` מדלג עליו ומאיץ את ההתחברות.

### פריסה לאינטרנט
- הריצו את שרת האיתות מאחורי TLS (`--certfile/--keyfile` או reverse proxy) וחברו עם `wss://`.
- חיבור P2P מצליח ברוב הרשתות. לרשתות קשות (NAT סימטרי) הקימו
  [coturn](https://github.com/coturn/coturn) והעבירו `--turn turn:host:3478,user,pass` למארח.

### בניית קובץ EXE ל-Windows
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name RDesk-Host   run_host.py
pyinstaller --onefile --windowed --name RDesk-Viewer run_viewer.py
```
שנו את `DEFAULT_SERVER` ב-`rdesk/protocol.py` לכתובת השרת שלכם לפני הבנייה.

## אבטחה

- **הצפנה מקצה לקצה:** DTLS‑SRTP של WebRTC. השרת לא רואה וידאו, קלט או קבצים.
- **אימות הדדי בעזרת הסיסמה:** ה-SDP (כולל טביעת האצבע של DTLS) נחתם ב-HMAC‑SHA256 עם הסיסמה
  ו-nonce חד-פעמי, לכן גם שרת איתות עוין לא יכול לבצע MITM. הסיסמה עצמה לא נשלחת.
- **המארח תמיד שולט:** חלון אישור עם הרשאות, מחוון "סשן פעיל" גלוי, כפתור ניתוק והרשאות שניתנות לביטול.
  ההרשאות נאכפות בצד המארח ולא נסמכות על הלקוח.
- הגנות: ולידציה של כל אירוע קלט, הגנת path traversal בקבצים, מגבלות גודל, rate‑limit בשרת, חסימת brute‑force.
- כדאי להשתמש בסיסמה ארוכה. אפשר לנסות לנחש אותה במצב לא-מקוון רק אם תוקף שולט בשרת האיתות *וגם* מצליח לצותת לשיחת האיתות.

> השתמשו רק במחשבים שלכם או כאלה שיש לכם הרשאה מפורשת לשלוט בהם.

```bash
python -m pytest -q
```
10 בדיקות מקצה לקצה (בלי תצוגה גרפית): וידאו, קלט, סיסמה שגויה וחסימה, דחייה, צפייה בלבד,

```
rdesk/files.py, clipboard.py
rdesk/gui_host.py, gui_viewer.py   ממשקי tkinter
```
