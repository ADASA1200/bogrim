# ניקוד קל: תוסף Word לניקוד

תוסף Word (Office.js) שמנקד מסמכים לפי מילון שהמשתמש בונה בעצמו. אפשר לעבוד מילה אחרי מילה ולבחור מתוך רשימת אפשרויות, או להריץ ניקוד על כל המסמך ולהגיה אחר כך.
התוסף עובד ב-Word לווינדוס (2016 ומעלה), ב-Word למק וב-Word באינטרנט.

הקוד והנתונים נכתבו כאן מאפס. המילון ההתחלתי (`data/starter-dictionary.json`) קטן, כ-60 ערכים שנכתבו ידנית, ונועד רק להדגמה. את המילון האמיתי בונים מקבצים מנוקדים שבבעלותכם (ראו "הוספת מילים").

## מה יש בגרסה הזו

**ניקוד אוטומטי** (לשונית "ניקוד"): מתחיל ממקום הסמן עד סוף המסמך, או רק בקטע שנבחר.
- המילה הנוכחית מסומנת במסמך, והאפשרויות מוצגות באותיות גדולות.
- בחירה: לחיצה (אחת או כפולה, לפי ההגדרות), Enter או רווח.
- **נקד תמיד**: כפתור, או Ctrl בזמן האישור. המילה תנוקד כך בכל המשך המסמך.
- **Alt בזמן האישור** מוסיף `$$` לפני המילה, לסימון מילים שצריך לבדוק.
- סידור המילון תוך כדי עבודה: ⤒ ↑ ↓ להזזה, ✕ או Delete למחיקה.
- ביטול (↶ או Ctrl+Z), כמה פעולות אחורה.
- שמירה אוטומטית של המסמך כל N מילים (ברירת המחדל 1000).

**הצעות חכמות**
- **אותיות השימוש** (ו ה ש ב כ ל מ): "לנתנאל" מקבל הצעות מ"נְתַנְאֵל" שבמילון. ההצעות מסומנות ב-`+`.
- **כתיב מלא לחסר**: "לימד" מקבל הצעה של "לִמֵּד". ההצעות מסומנות ב-`–`.
- **ראשי תיבות**: ערך כמו `ע"ה → עָלָיו הַשָּׁלוֹם` פותח את הקיצור.
- מילים שמחוברות במקף עליון או רגיל (אף־על־גב, בית-ספר) מטופלות כמילים נפרדות.
- סוגריים, פיסוק, ספרות וגרשים שצמודים למילה לא מפריעים לזהות אותה.

**ניקוד ידני** (בתחתית הלשונית): כאן מנקדים מילה שאינה במילון.
- מקשים: 1 שווא · 2 חיריק · 3 צירה · 4 סגול · 5 פתח · 6 קמץ · 7 חולם · 8 קובוץ · 9 דגש/שורוק · 0 שין ימנית · `-` שין שמאלית · Shift+4/5/6 חטפים · `=` מתג. כל הסימנים מופיעים גם ככפתורים.
- Enter = **הוסף והמשך**: מכניס את המילה למסמך וגם למילון.
- Shift+Enter = **המשך**: מכניס את המילה למסמך בלבד.
- אפשר גם לשנות את גוף המילה, למשל לכתוב "עַכְשָׁו" במקום "עכשיו", או לכתוב את הפתיחה של ראשי תיבות. התוסף זוכר את השינוי לפעם הבאה.

**מילה בודדת**: ניקוד או תיקון של המילה שבמקום הסמן בלבד.

**לשונית "מקלדת"**: כפתורי ניקוד וטעמי המקרא שמוכנסים למסמך במקום הסמן, והסרה של ניקוד או של טעמים בלבד מהבחירה.

**לשונית "מילון"**
- חיפוש, הוספה וסידור של מילים.
- הוספת מילה לא מנוקדת, או מילה תחת מפתח מיוחד.
- **שמירת גיבוי** לקובץ JSON, וטעינה מקובץ גיבוי או מקובץ טקסט.

**לשונית "הגדרות"**: כל אפשרויות הדילוג וההרצה. יש שתי קבוצות מוכנות: "ברירת מחדל" (ניקוד חצי-אוטומטי) ו"הרצת ניקוד".

### קיצורי מקשים בחלונית

| מקש | פעולה |
|---|---|
| ↑ ↓, Home, End, PgUp, PgDn | מעבר בין האפשרויות |
| Enter או רווח | אישור |
| Ctrl+Enter | אישור + נקד תמיד |
| Alt+Enter | אישור + `$$` |
| → | חזור מילה |
| ← | דלג |
| Shift+← | עבור למילה הבאה גם אם היא מנוקדת |
| Ctrl+↓ | מעבר לניקוד ידני |
| Ctrl+↑ | חזרה לרשימה |
| Delete | מחיקת האפשרות מהמילון |
| Ctrl+Z | ביטול |
| Ctrl+Shift+S | הגדרות |
| Esc | סיום |

## הוספת מילים למילון

- **מתוך Word**: בוחרים טקסט מנוקד ולוחצים "הוסף מילים מהבחירה למילון".
- **מקובץ טקסט**: לשונית "מילון", ואז "טען קובץ". הקובץ יכול להיות טקסט מנוקד רגיל, או שורות בפורמט `מפתח<TAB>צורה<TAB>צורה`, למשל `עכשיו	עַכְשָׁו`.
- המילון נשמר במחשב, באחסון של החלונית (IndexedDB). כדאי לשמור גיבוי מדי פעם.

## הרצה בפיתוח

דרוש Node.js 18 ומעלה.

```bash
cd nikud-addin
```

```bash
npm install
```

```bash
npm run certs
```

```bash
npm start
```

אחר כך, בחלון אחר:

```bash
npm run sideload
```

`npm run certs` מתקין תעודת localhost לפיתוח, ונדרש פעם אחת בלבד. `npm start` מגיש את התוסף בכתובת `https://localhost:3000`. `npm run sideload` פותח את Word עם התוסף טעון. אפשר גם לטעון את `manifest.xml` ידנית: ב-Word באינטרנט דרך "הוספות" ואז "העלאת תוספת"; בווינדוס דרך תיקייה משותפת שמוגדרת כ"קטלוג תוספות מהימן".

הכפתור **"ניקוד"** יופיע בלשונית "בית".

### בדיקות

```bash
npm test
```

```bash
node test/ui-smoke.cjs
```

הראשונה מריצה בדיקות יחידה ללוגיקה: פירוק מילים, אותיות שימוש, כתיב חסר, המילון וההחלטות. השנייה בודקת את החלונית בדפדפן מול Word מדומה (`test/fake-word.js`), ודורשת Playwright.

## השלבים הבאים

1. **ניקוד פסוקים**: חיפוש פסוק לפי כמה מילים, החלפה בנוסח המנוקד, ואפשרות להוסיף מקור ומירכאות. צריך לבחור לזה מקור טקסט חופשי לשימוש, למשל כתר ארם צובה או כתב יד לנינגרד בגרסה הדיגיטלית הפתוחה. יש לבדוק את הרישיון של המקור לפני שמכניסים אותו.
2. **קיצורי מקשים בתוך Word** (F5 עד F8): ב-Office.js זה דורש Shared Runtime ו-Keyboard Shortcuts API.
3. **ייבוא מהיר של מילונים גדולים**: עיבוד ברקע עם מד התקדמות.
4. **הפצה**: אירוח קבוע ב-HTTPS, עדכון הכתובות ב-`manifest.xml`, והפצה ארגונית או דרך AppSource.

## מגבלות ידועות

- כשהאותיות במילה לא משתנות, הניקוד מוכנס אחרי כל אות בנפרד, וכך נשמר העיצוב של חלקי המילה. כשהאותיות משתנות (כתיב חסר, פתיחת ר"ת) או כשהמילה כבר מנוקדת, המילה מוחלפת כולה ומקבלת את העיצוב של האות הראשונה.
- "הסר ניקוד מהבחירה" מחליף מילה שלמה בכל פעם, ולכן גם הוא שומר רק את העיצוב של האות הראשונה.
- ניקוד אותיות השימוש מבוסס על כללי דקדוק בסיסיים. לכן ההצעות מסומנות ב-`+`, וצריך לעבור עליהן.
