# חוסם וידאו לאנדרואיד (VideoBlock)

גרסת אנדרואיד ברוח **Videoff** (תוכנת Windows שחוסמת כל סוגי הווידאו במחשב).
התוכנה פועלת כ־**Device Owner** (בעלים של המכשיר). זו הרשאת הניהול הגבוהה ביותר שאנדרואיד נותן לאפליקציה,
ובה משתמשים גם פתרונות "טלפון כשר" ומערכות MDM ארגוניות.

## מה נחסם

| שכבה | מה עושה |
|---|---|
| אפליקציות | כל אפליקציה שיכולה לפתוח קובץ וידאו (נגנים, גלריות, מנהלי קבצים) וכל דפדפן מושעית (Suspended). אפליקציות וידאו מוכרות (YouTube, TikTok, Netflix, Instagram ועוד) גם מוסתרות לגמרי. |
| התקנות חדשות | כל אפליקציה שמותקנת נבדקת מיד, ואם היא מסוגלת להציג וידאו היא נחסמת. התקנה ממקורות לא ידועים (APK) חסומה. |
| רשת (DNS) | VPN מקומי שמופעל תמיד ומסנן DNS. הוא חוסם את כל אתרי ושרתי הווידאו (YouTube/googlevideo, TikTok, Vimeo, Netflix, אתרי VOD ישראליים ועוד) בכל האפליקציות, כולל דפדפן שהמנהל שחרר. השאילתות האחרות עוברות ל־Cloudflare for Families, שחוסם גם תוכן למבוגרים. שרתי DNS-over-HTTPS חסומים כדי שלא אפשר יהיה לעקוף. |
| מצלמה | אפשרות לחסום את המצלמה (צילום וידאו). |
| קבצים | אין העברת קבצים ב־USB ואין כרטיס זיכרון / דיסק און קי. |

## הגנה מפני הסרה ועקיפה

- אי אפשר להסיר את התוכנה (Uninstall חסום, ו־Device Owner לא ניתן להסרה מההגדרות).
- אי אפשר לבצע איפוס להגדרות היצרן מתפריט ההגדרות.
- מצב בטוח (Safe Mode), אפשרויות מפתחים ו־ADB חסומים, ולכן אי אפשר להסיר את התוכנה גם דרך המחשב.
- אי אפשר לכבות את ה־VPN, להחליף אותו ב־VPN אחר או לשנות את "DNS פרטי".
- אי אפשר לעצור בכוח, לנקות נתונים או לבטל השעיה של אפליקציות.
- אי אפשר להוסיף משתמש או אורח. גם שינוי שעה חסום, כדי שלא יאפשר לעקוף את נעילת הקוד.
- קוד מנהל: מוצפן ב־PBKDF2. אחרי 5 ניסיונות שגויים יש נעילה מתארכת (1, 2, 4 דקות וכן הלאה, עד 24 שעות).
- **נעילה לצמיתות**: אחרי שמפעילים אותה אין דרך לשנות הגדרות או להסיר את ההגנה, גם לא עם הקוד.

## התקנה

1. בנייה: `./gradlew assembleRelease` וחתימה במפתח שלך (או שימוש ב־`app-debug.apk` לבדיקה).
2. התקנה במכשיר: `adb install app-debug.apk`
3. מחיקת **כל** החשבונות מהמכשיר (הגדרות ← חשבונות). זו דרישה של אנדרואיד להגדרת Device Owner. אפשר להחזיר אותם אחר כך.
4. הפעלה:
   ```
   adb shell dpm set-device-owner org.videoblock/.AdminReceiver
   ```
5. פתיחת התוכנה והגדרת קוד מנהל. מומלץ למסור את הקוד לאדם אחר.

כדאי להתקין לפני שמכניסים מידע למכשיר. אם אפשר, עדיף מכשיר חדש או מכשיר אחרי איפוס.

## מגבלות (בכנות)

- **איפוס מלא ממצב Recovery** (שילוב מקשים בהדלקה) לא ניתן לחסימה על ידי שום אפליקציה, וגם לא על ידי Videoff במחשב (פירמוט).
  אחרי איפוס כזה התוכנה נמחקת. מה שעוזר: הגנת FRP של Google (אחרי האיפוס המכשיר מבקש את חשבון Google הקודם) ושמירת הסיסמה של החשבון אצל אדם אחר.
- **וידאו בתוך אפליקציות שהמנהל השאיר פתוחות** (למשל וואטסאפ וטלגרם) לא מסונן, כי התמונות והסרטונים מגיעים מאותם שרתים.
  אם צריך, אפשר לסמן גם אותן כחסומות במסך הניהול.
- דפדפן שהמנהל שחרר חסום רק לאתרי וידאו שברשימה. סרטון באתר לא מוכר עלול לעבור. כברירת מחדל כל הדפדפנים חסומים.
- קבצי וידאו שכבר נמצאים במכשיר לא נמחקים, אבל כל האפליקציות שיכולות לנגן אותם חסומות.
- הגלריה חסומה (כי היא מנגנת וידאו). אפשר לשחרר אותה במסך הניהול, אבל אז אפשר לצפות דרכה בסרטונים.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `Policy.kt` | כל ההגבלות: Device Owner, זיהוי וחסימה של אפליקציות, שחרור |
| `DnsVpnService.kt` | שרת ה־DNS המסנן (VPN מקומי) |
| `Blocklist.kt` | רשימת אפליקציות ואתרי וידאו |
| `Prefs.kt` | הגדרות וקוד מנהל |
| `MainActivity.kt`, `AdminActivity.kt` | ממשק משתמש |
| `Receivers.kt` | הפעלה מחדש באתחול ובדיקה כל 15 דקות |
